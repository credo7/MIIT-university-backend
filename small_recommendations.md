### 1. **Проблема с паролями - `.lower()`**
**Файлы:** `src/api/auth.py:32, 93`

**Проблема:**
```python
hashed_password = utils.hash(user_dto.password.lower())  # ❌
if not utils.verify(user_credentials.password.lower(), user_db['password']):  # ❌
```

**Почему важно:**
- Все пароли становятся lowercase - студент может ввести "Пароль123" при регистрации, а войти только через "пароль123"
- Путаница у пользователей - "почему пароль не работает?"
- Снижает надежность паролей в 10+ раз

**Как исправить:**
```python
# Убрать .lower() в обоих местах
hashed_password = utils.hash(user_dto.password)  # ✅
if not utils.verify(user_credentials.password, user_db['password']):  # ✅
```

**Время:** 2 минуты
**Важность:** 🔥🔥🔥 Будут жалобы студентов!

### 2. **WebSocket не работает с несколькими workers**
**Файл:** `src/db/state.py`

**Проблема:**
```python
class WebsocketServiceState:
    connected_computers: dict[int, ConnectedComputer] = {}  # In-memory словарь
    active_connections: dict[int, WebSocket] = {}
```

Если запустить с `--workers 4`, каждый worker будет иметь свой словарь → WebSocket соединения будут теряться.

**Решение:**
Либо:
1. **Запускать только с 1 worker** (для локалки норм):
   ```bash
   uvicorn src.main:app --host 0.0.0.0 --port 80  # БЕЗ --workers
   ```
2. Или переписать на Redis (если нужно несколько workers)

**Время:** 0 минут (просто не добавлять `--workers`)
**Важность:** 🔥🔥 Иначе WebSocket работать не будет!

### 4. **Пустые exception handlers - теряются ошибки**
**Файл:** `src/api/ws.py:52-53`

```python
except WebSocketDisconnect as exc:
    pass  # ❌ Ошибка молча проглатывается
```

**Почему плохо:**
Если что-то сломается - не узнаете об этом. Отладка станет кошмаром.

**Решение:**
```python
except WebSocketDisconnect as exc:
    logger.debug(f"WebSocket отключен: {exc}")  # ✅ Хотя бы в лог
```

**Время:** 2 минуты
**Важность:** 🟡 Поможет при отладке

**Текущее:** Логи пишутся в `../app.log` без ротации (кроме Docker)

**Если не Docker:**

```python

handler = RotatingFileHandler(
    settings.log_file,
    maxBytes=10*1024*1024,  # 10MB
    backupCount=5
)
```
